# StoryBit - Streaming Dashboard (Next.js 14 + TypeScript + Tailwind)

This project is a simplified streaming dashboard clone (Netflix-like) built to satisfy the StoryBit Frontend Developer task.

## Setup (locally)

1. Copy `.env.local.example` to `.env.local` and set `TMDB_API_KEY`.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run dev:
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000

## Notes
- The TMDB API key must be stored in `.env.local` (server-side usage).
- Deploy to Vercel and add `TMDB_API_KEY` to Vercel Environment Variables.
